# splineROM

This repository is under construction. It is updated continuously with the code and data accompanying the following publications:

[1] V. Chheda, M. Chasapi, Reducing parametric problems with discontinuities using deep learning, Proceedings in Applied Mathematics and Mechanics.

The paper deals with deep learning-based reduced order modelling of problems in solid mechanics that contain discontinuities. It provides a comparison between POD-based and autoencoder-based reduced order models for parametric problems involving discontinuities that are induced by geometric and material parameters.
